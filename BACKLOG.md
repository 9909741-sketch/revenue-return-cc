# Бэклог. Возврат выручки контакт-центра (MoSCoW)

## Must — MVP (5 функций, один автономный прогон)

1. Импорт выгрузки Б24 (XLSX/CSV) с дедупликацией и обработкой ошибок/пустых сумм.
2. Задачник «Отмены» со статусной моделью и обязательным комментарием при закрытии.
3. Задачник «Тёплые лиды» с графиком касаний 3/7/14/30 дней и автозакрытием.
4. Отчётность по обоим модулям: метрики, разрезы, сравнение периодов, экспорт CSV.
5. Пользователи и роли: 4 роли, серверная проверка доступа.

## Should — Фаза 2

- Живая интеграция с Б24 REST API вместо ручной выгрузки — добавляется после подтверждения гипотезы на MVP.
- Telegram-уведомления операторам о новых задачах и просрочке SLA — повышает скорость реакции без переписывания ядра.
- Автоэскалация просроченных задач руководителю КЦ — требует накопленной статистики по SLA.
- Отчёты по расписанию на email — удобство, не критично для проверки гипотезы.
- Настраиваемый справочник товарных групп — нужен только при росте ассортиментной аналитики.

## Could — Фаза 3

- Сверка с КП 1С — отдельный источник данных, усложняет импорт, нужна только при расхождениях с Б24.
- Скоринг перспективности реанимации по истории причин и оператора — требует накопленных данных за несколько месяцев.
- Контрольная группа (A/B) для замера чистого эффекта — усложняет процесс, оправдана после стабилизации пилота.
- Встроенная телефония (клик-ту-колл, запись звонков) — существенное расширение архитектуры.

## Won't — Антископ (с причинами)

| Пункт | Причина |
|---|---|
| Прямая интеграция с Б24 через REST API на старте | Не сейчас — ручная выгрузка надёжнее для одного автономного прогона |
| Мотивация и депремирование сотрудников ТТ внутри инструмента | Никогда — зона HR и юриста, не продуктовая функция |
| Мобильное приложение (iOS/Android) | Никогда — оператору достаточно адаптивного веба на рабочем месте |
| Встроенная телефония, клик-ту-колл, запись звонков | Не сейчас — оператор пользуется текущей телефонией компании |
| Интеграция с КП 1С | Не сейчас — единственный источник на MVP — выгрузка Б24 |
| Онлайн-оплата и платёжный контур | Есть готовое решение — оплата идёт через существующие кассы |
| SMS-рассылки клиентам | Не сейчас — первый канал возврата — звонок оператора |

## Ключевые проектные решения

Правило пяти функций соблюдено строго: два задачника считаются как две функции, а не как модуль плюс подмодули, потому что они реализуются на общем ядре данных, но с разными статусными моделями и экранами.
