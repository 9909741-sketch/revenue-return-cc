## Дополнительные проверки

1. **Установка зависимостей без ошибок** — **Требует внимания**. `npm install` в исходном виде падает на пакете `xlsx`, который в package.json указан по прямой ссылке на `https://cdn.sheetjs.com/...` (официальная рекомендация SheetJS, т.к. пакет снят с npm-реестра). В моей проверочной среде это доменное имя блокируется сетевой политикой песочницы (тот же тип ограничения, из-за которого сам Claude Code не смог поставить зависимости) — это ограничение среды проверки, а не обязательно проблема на Replit, но проверь при первом деплое: если Replit тоже не пропустит этот домен, самый простой обход — временно поставить `xlsx@^0.18.5` из обычного npm-реестра (у него не самая новая версия с уязвимостями низкого риска, но для внутреннего инструмента это приемлемо) и заменить перед промышленной эксплуатацией.
2. **Сборка проходит без ошибок** — **Не принято, исправлено при проверке**. `npm run build` в исходном виде падает с ошибкой типов TypeScript в `server/src/routes/taskRoutes.ts` (три места: `req.params.id` в актуальных типах Express 5 имеет тип `string | string[]`, а функции ожидают `string`). После правки (обёртка `String(req.params.id)` в этих трёх местах) сборка и вход, и весь основной сценарий прошли без ошибок. Это единственный найденный дефект кода — исправляется тремя строками, промпт-доводчик ниже.

   **Дополнение после рестайлинга (2026-09-25)**: после этой проверки внесена ещё одна правка — замена палитры на брендовую (docs/RESTYLE_PROMPT.md). Она меняет только значения CSS-переменных в `client/src/index.css` и JSX-текст/классы в `client/src/components/Layout/AppLayout.tsx` — ни типов, ни импортов, ни логики. В песочнице Claude Code по-прежнему нет `node`/`npm` (проверено ещё раз перед этой правкой), поэтому `npm run build` для этой конкретной правки заново не запускался ни агентом, ни (пока) Автовайбкодером — состояние по этой конкретной правке честно: «не проверено» (не «принято»), хотя риск ошибки компиляции у правки такого рода минимален.
3. **Главный сценарий целиком (импорт → задачник → фиксация звонка → отчёт)** — **Принято** — пройден вживую от начала до конца на реальном PostgreSQL.
4. **Все экраны из SPEC открываются и не пустые** — **Требует твоей проверки**. Я проверил все маршруты на уровне сервера и данных (роуты в App.tsx покрывают все 9 экранов из паспорта), но открыть их глазами в браузере и оценить внешний вид я не могу — после `npm run dev` пройди по всем пунктам меню и убедись, что ничего не выглядит пустым или сломанным.
5. **Реальных ключей и паролей в репозитории нет** — **Принято** — `.env.example` содержит пустые значения, `.gitignore` исключает `.env`. Демо-пароль используется только для локальных тестовых учёток; production создаёт первого администратора из отдельного секрета, а demo credentials не включены.
6. **Архив собран и не содержит node_modules** — **Принято** — проверил состав `deploy/revenue-return-cc-replit.zip` (86 файлов): node_modules/.git/dist/.env отсутствуют. `package-lock.json` в архиве нет (появится после твоего первого `npm install`) — это честно и корректно, брака здесь нет.

   **Дополнение после рестайлинга**: архив пересобран заново из текущего состояния папки после правки палитры (см. docs/CHANGELOG.md) — состав файлов не менялся, поменялось только содержимое `client/src/index.css` и `client/src/components/Layout/AppLayout.tsx` внутри архива.
