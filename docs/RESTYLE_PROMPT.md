## Задача

Заменить рабочую (не брендовую) цветовую палитру интерфейса на официальную палитру
Laparet. Это правка стилей, а не новая функциональность — состав экранов, API,
модель данных и права доступа не меняются.

## Что поменять

Единственный источник цветовых токенов — `client/src/index.css`, блок `@theme` и блоки
`:root` / `.dark`. Замени значения на следующие (полностью, без частичного смешивания
старого и нового):

```
@theme {
  --font-sans: "Inter", ui-sans-serif, system-ui, -apple-system, "Segoe UI", sans-serif;

  --color-brand-bg: #f0e8e2;
  --color-brand-fg: #231e1e;
  --color-brand-primary: #aa7d64;
  --color-brand-accent: #c09978;
  --color-brand-error: #d64550;
  --color-brand-success: #2e7d32;
}

:root {
  --page-bg: var(--color-brand-bg);
  --page-fg: var(--color-brand-fg);
  --surface-bg: #ffffff;
  --surface-border: #d7c5c1;
  --muted-fg: #8a7a73;
}

.dark {
  --page-bg: #231e1e;
  --page-fg: #f0e8e2;
  --surface-bg: #2e2724;
  --surface-border: #4a3d38;
  --muted-fg: #c8b9b7;
}
```

`--color-brand-error` и `--color-brand-success` не меняются — это функциональные цвета
статуса (красный/зелёный), не часть брендовой палитры, менять их нельзя.

Новый токен `--color-brand-accent` (#c09978) используй для вторичных акцентов и
hover-состояний там, где сейчас жёстко прописаны оттенки `black/5` или `white/10`
(например, в `client/src/components/Layout/AppLayout.tsx`, пункт меню в неактивном
состоянии при наведении) — замени на полупрозрачный вариант акцентного цвета, если это
не усложняет код существенно; если решишь оставить как есть — это не критично, впиши
решение в CHANGELOG.

Пройдись поиском по всему `client/src` на предмет цветов, зашитых в код в обход токенов
темы (прямые HEX или `text-green-...`/`bg-slate-...` и подобные классы Tailwind вместо
`text-brand-*`/`bg-brand-*`/`var(--...)`). Замени найденное на переменные темы. Если
что-то осознанно не тронул — укажи причину в CHANGELOG.

## Логотип

Готового файла логотипа (SVG/PNG) нет — брендбук пришёл только страницами PDF, из них
нельзя надёжно извлечь чистый векторный знак. Логотип-картинку не добавляй и не рисуй
сам. Вместо этого:

- в `client/src/components/Layout/AppLayout.tsx` замени текстовую метку в шапке боковой
  панели (сейчас `<div className="mb-6 text-sm font-semibold text-brand-primary">Возврат
  выручки КЦ</div>`) на два уровня: словесная часть «LAPARET» — крупнее, жирным
  начертанием, заглавными буквами, разрядка букв (`tracking-wide` или аналог), цвет
  `text-brand-primary`; ниже — «Возврат выручки КЦ» мельче и обычным начертанием, цвет
  `text-[var(--muted-fg)]`.
- никаких выдуманных иконок (ракушка, веер и подобное) не рисуй — только текст.

## После изменений

1. Обнови комментарий в начале `client/src/index.css` (сейчас он ссылается на
   docs/PASSPORT.md, блок 9 — палитра уже актуальна, менять комментарий не обязательно,
   если он не противоречит фактическим значениям).
2. Добавь запись в docs/CHANGELOG.md: что изменено, откуда взята палитра, что логотип
   пока текстовый.
3. Прогони docs/ACCEPTANCE.md целиком, не только изменённую часть, проставь три
   состояния честно (эта правка не должна была задеть ни один из 12 критериев — если
   что-то всё же задела, это нужно явно отметить).
4. Собери фронтенд (`npm run build` в client) и пересобери архив
   `deploy/revenue-return-cc-replit.zip`.
5. Сделай локальный коммит: `git add -A && git commit -m "Рестайлинг: брендовая палитра Laparet"`.
6. Выведи короткий отчёт: какие файлы изменены, что не менялось намеренно, где лежит
